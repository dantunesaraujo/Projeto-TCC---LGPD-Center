Aviso de Privacidade

Última atualização: Outubro de 2026 (Versão 1.0)

1. Apresentação

O LGPD Center é um sistema desenvolvido para auxiliar pequenas empresas na avaliação de sua maturidade em relação à Lei Geral de Proteção de Dados Pessoais (Lei nº 13.709/2018 — LGPD).

Este Aviso de Privacidade tem como objetivo informar como os dados pessoais fornecidos durante a utilização do sistema são tratados, apresentando as finalidades de uso, as medidas de proteção adotadas e os direitos dos titulares.

2. Quais dados são coletados?

Durante a utilização do LGPD Center, poderão ser tratados os seguintes dados pessoais: dados cadastrais da empresa, como razão social ou nome fantasia e CNPJ; e dados de contato, como nome do responsável pela proteção de dados e endereço de e-mail.

O sistema não solicita, como parte de sua finalidade principal, o cadastro de dados pessoais sensíveis.

3. Para quais finalidades os dados são utilizados?

Os dados tratados pelo sistema podem ser utilizados para identificar a empresa cadastrada, permitir o preenchimento e o acompanhamento das avaliações de conformidade com a LGPD, calcular indicadores de maturidade, apresentar resultados por área avaliada, gerar relatórios e disponibilizar orientações gerais sobre proteção de dados pessoais. Os dados não devem ser utilizados para finalidades incompatíveis com aquelas informadas neste Aviso de Privacidade.

4. Como os dados são armazenados e protegidos?

O LGPD Center adota medidas de segurança compatíveis com suas características técnicas para buscar proteger os dados contra acessos não autorizados, perda, alteração ou divulgação indevida.

5. Compartilhamento de dados

Os dados cadastrados não devem ser compartilhados com terceiros, exceto quando necessário para a operação do sistema, mediante fundamento legal aplicável ou nas demais hipóteses permitidas pela legislação. Caso sejam utilizados serviços externos de hospedagem, armazenamento ou processamento de dados, o compartilhamento deverá observar as finalidades informadas, as medidas de segurança pertinentes e os requisitos aplicáveis da LGPD.

6. Por quanto tempo os dados são mantidos?

Os dados serão mantidos pelo período necessário ao cumprimento das finalidades para as quais foram coletados, considerando as funcionalidades do sistema e as obrigações legais aplicáveis. Quando os dados deixarem de ser necessários, sua eliminação ou anonimização poderá ocorrer, ressalvadas as hipóteses de conservação permitidas pela legislação.

7. Direitos dos titulares

Nos termos da LGPD, os titulares de dados pessoais podem solicitar, conforme aplicável, a confirmação da existência de tratamento, o acesso aos dados, a correção de informações incompletas, inexatas ou desatualizadas, a anonimização, o bloqueio ou a eliminação de dados desnecessários ou tratados em desconformidade com a legislação, bem como informações sobre o compartilhamento de seus dados. Também podem solicitar a eliminação de dados tratados com base no consentimento e revogar esse consentimento, observadas as condições e exceções previstas na legislação.

8. Alterações neste Aviso de Privacidade

Este Aviso de Privacidade poderá ser atualizado para refletir alterações nas funcionalidades do LGPD Center, nas práticas de tratamento de dados ou na legislação aplicável. A versão atualizada deverá ser disponibilizada aos usuários por meio do próprio sistema.

9. Contato

Para esclarecer dúvidas ou encaminhar solicitações relacionadas ao tratamento de dados pessoais, entre em contato com o responsável pelo LGPD Center pelo contato atendimento@lgpdcenter.com.br.
